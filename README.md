# Crodl desktop downloads

Official installers and release notes for Crodl Quant. This repository distributes packaged applications; application source is maintained in a separate private repository.

## Mac beta

**Supported:** Apple Silicon (arm64), macOS 14 or newer.

[Download Crodl Quant for Mac](https://github.com/Crodl/crodl-downloads/releases/download/v1.4.7-beta.2518.14.13/Crodl-Quant-1.4.7-20261123T141315Z-arm64.zip)

[Release notes and checksums](https://github.com/Crodl/crodl-downloads/releases/tag/v1.4.7-beta.2518.14.13) · [All releases](https://github.com/Crodl/crodl-downloads/releases)

1. Download and extract the ZIP.
2. Move **Crodl Quant.app** to **Applications** before opening it.
3. Open Crodl Quant and sign in with Crodl.

Intel Mac, Windows and Linux installers are not currently offered.

This is the beta channel. Use the app's **Feedback** menu to report problems or request features. Third-party notices are included in the application.

## About GitHub's source archive links

GitHub automatically adds **Source code (zip)** and **Source code (tar.gz)** links to releases. They archive the files in this downloads repository, such as this README. They do not grant access to Crodl's private application source repository. To install the app, use the **Crodl-Quant-...-arm64.zip** installer asset above.
